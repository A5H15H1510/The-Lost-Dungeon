# The-Lost-Dungeon
A text-based dungeon RPG made in C++ as a learning project.

## Features

- Random dungeon encounters
- Turn-based combat
- Goblins, wolves, and bandits
- Randomized enemy HP, damage, XP, and gold
- XP and leveling system
- Increasing HP and attack power
- Health potions
- Weapon upgrade system
- Shop
- Rest/Inn system
- Character statistics
- Game Over system
- Input validation

## Gameplay

Enter the dungeon and fight enemies to earn XP and gold.

Use your gold to:
- Buy health potions
- Upgrade your sword
- Rest at the inn

Level up by earning enough XP to increase your attack power and maximum HP.

## Built With

- C++
- Standard C++ libraries

## Purpose

This project was created while learning C++ and practicing:

- Variables and data types
- Conditionals
- Loops
- Switch statements
- Random number generation
- Input validation
- Strings
- Basic game logic
